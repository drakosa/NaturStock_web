# Plugins — NaturaStock Cusco

Actualmente no hay plugins activos en el proyecto.

## ¿Qué es un plugin?

En el contexto de SDD, un plugin es un módulo opcional que extiende la funcionalidad del proyecto sin modificar el código base. Los plugins se integran a través de hooks o puntos de extensión definidos.

## Futuros plugins (sugeridos)

- **Exportador de reportes** — Exportar reportes a PDF/Excel.
- **Notificaciones por email** — Alertas de stock bajo vía email.
- **Respaldo automático** — Backup periódico de la base de datos.

Para agregar un plugin, crear una carpeta dentro de `plugins/` con su propia documentación y especificación.
