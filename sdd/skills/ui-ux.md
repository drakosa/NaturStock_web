# UI/UX Skill

## Design System

### Paleta de colores
| Token | Color | Hex |
|-------|-------|-----|
| Primario | Verde Bosque | #154212 |
| Secundario | Verde Salvia | #4a6549 |
| Terciario | Beige Terroso | #383a37 |
| Superficie | Fondo claro | #f8f9ff |

### Tipografía
- **Font family**: Inter (sans-serif)
- **Fuente de iconos**: Font Awesome (CDN)

### Componentes
- Botones con clases `.btn`, `.btn-primary`, `.btn-secondary`, `.btn-danger`.
- Tablas con clase `.table`.
- Formularios con clase `.form-group`.
- Tarjetas con clase `.card`.
- Notificaciones toast (implementadas en `app.js`).

## Principios
- Diseño responsive (mobile-first donde sea posible).
- Feedback visual inmediato para acciones del usuario.
- Estados de carga (spinner/placeholder) para operaciones asíncronas.
- Mensajes de error claros y visibles.
- Consistencia en espaciado, tipografía y colores.
