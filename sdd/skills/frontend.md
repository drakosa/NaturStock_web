# Frontend Skill

## Tecnologías
- HTML5
- CSS3 (Design System con variables CSS / Design Tokens)
- JavaScript vanilla (ES6+)
- Sin frameworks ni librerías externas

## Convenciones
- Funciones en camelCase.
- IDs y clases en kebab-case.
- Las secciones de la SPA se muestran/ocultan con clases `hidden`/`visible`.

## Archivos que puedes modificar (con autorización)
- `index.html` — estructura DOM.
- `style.css` — estilos y design tokens.
- `app.js` — lógica de frontend (solo con permiso explícito).

## Restricciones
- No cambiar la estructura de la SPA sin especificación previa.
- No añadir dependencias externas (CDNs, librerías) sin autorización.
- Mantener consistencia visual con la paleta andina actual.
- No romper la funcionalidad de navegación entre secciones.
