# Roadmap — NaturaStock Cusco

Futuras mejoras planificadas para el proyecto. Ninguna está implementada aún.

## Corto plazo

- [ ] **Punto de Venta (POS)** — Interfaz optimizada para registro rápido de ventas con selección táctil de productos y cálculo automático de vuelto.
- [ ] **Gestión de imágenes desde el frontend** — Subir imágenes de productos directamente desde la interfaz (actualmente se ingresan rutas manualmente).

## Mediano plazo

- [ ] **Dashboard avanzado** — Gráficos interactivos (ventas por mes, productos más vendidos, tendencias de stock) usando Chart.js o similar.
- [ ] **Reportes en PDF** — Generar reportes de stock, ventas e inventario en formato PDF descargable.
- [ ] **Exportación a Excel** — Exportar tablas de productos, ventas, clientes e inventario a formato XLSX.

## Largo plazo

- [ ] **Control de movimientos avanzado** — Aprobación de movimientos de inventario por roles, con registro de auditoría.
- [ ] **Historial de auditoría** — Registro detallado de todas las operaciones (quién, qué, cuándo) para trazabilidad completa.
- [ ] **Módulo de usuarios con roles** — Gestión de múltiples usuarios con permisos diferenciados (admin, vendedor, almacenero).
- [ ] **Notificaciones** — Alertas por email o notificaciones in-app para stock bajo, ventas grandes, etc.

## Priorización

| Mejora | Impacto | Esfuerzo | Prioridad |
|--------|---------|----------|-----------|
| POS | Alto | Medio | Alta |
| Gestión de imágenes | Alto | Bajo | Alta |
| Dashboard avanzado | Medio | Medio | Media |
| Reportes PDF | Medio | Medio | Media |
| Exportación Excel | Medio | Bajo | Media |
| Control de movimientos | Alto | Alto | Baja |
| Historial de auditoría | Alto | Alto | Baja |
| Usuarios con roles | Alto | Alto | Baja |
| Notificaciones | Medio | Medio | Baja |

> **Nota**: Cada mejora debe ser especificada en un documento dentro de `specs/` antes de iniciar su implementación, siguiendo el flujo SDD del proyecto.
