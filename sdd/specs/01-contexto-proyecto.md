# Contexto del Proyecto

## Nombre

**NaturaStock Cusco** — Sistema de Gestión e Inventario para Productos Naturales.

## Ubicación

Cusco, Perú. Negocio dedicado a la comercialización de productos naturales (plantas medicinales, extractos, aceites esenciales, etc.).

## Problema

El negocio requiere un sistema digital para gestionar su inventario, ventas, clientes y proveedores, reemplazando métodos manuales o herramientas genéricas no adaptadas a su rubro.

## Solución

Aplicación web SPA (Single Page Application) construida con HTML, CSS y JavaScript vanilla, con base de datos en Supabase (PostgreSQL) y desplegada en Vercel.

## Usuarios

| Rol | Descripción |
|-----|-------------|
| Administrador | Acceso completo al sistema: CRUD de productos, ventas, inventario, reportes. |

## Stack tecnológico

- **Frontend**: HTML5 + CSS3 (Design System propio) + JavaScript vanilla
- **Backend**: Supabase (PostgreSQL)
- **Deployment**: Vercel
- **Autenticación**: Login local (no Supabase Auth)
- **Moneda**: Soles Peruanos (S/)
